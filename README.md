# 🚀 HypeX

### ⚡ AI-Powered Sports Engagement Platform

HypeX is a project built during the **Build with AI: Agentic Premier League** event organized by Google Developer Groups Gandhinagar 🏏🤖

The platform focuses on enhancing live sports experiences using AI, real-time updates, and interactive engagement features.

---

## ✨ Features

- 🏏 Real-time sports interaction
- 🤖 AI-powered experience
- ⚡ Fast and responsive UI
- 👥 Collaborative team project
- 🚀 Scalable architecture

---

## 🛠️ Tech Stack

- React / Next.js
- Node.js / Express
- Gemini API / OpenAI
- MongoDB / Firebase
